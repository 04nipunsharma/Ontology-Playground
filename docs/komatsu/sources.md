# Sources

Public sources behind the Komatsu-specific facts, system mappings and
standards alignments in this ontology. The research was done in September 2026.
Many Komatsu pages could only be read through search-engine summaries, so
check against the live page before treating any fact as authoritative.
Items that could not be confirmed are in [open-questions.md](open-questions.md).

Personal profiles (e.g. LinkedIn) were used only to confirm that role titles
exist. They are deliberately not listed here.
